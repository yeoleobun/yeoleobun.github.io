# yeoleobun.github.io

Personal homepage, project showcase, and technical blog for **yeoleobun** — featuring native macOS developer utilities (**[Quota](https://github.com/yeoleobun/Quota)** and **[Grove](https://github.com/yeoleobun/Grove)**) alongside writing on systems programming, Rust, concurrency, and mathematics.

## Development

Built with [Astro](https://astro.build) and [Tailwind CSS](https://tailwindcss.com).

```bash
npm install
npm run dev
```

## Build & Preview

```bash
npm run build
npm run preview
```
